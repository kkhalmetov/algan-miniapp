# Algan redesign reference

These boards define the visual direction implemented in the customer Telegram Mini App:

- `01-brand-identity.png` — two-colour Algan mark, wordmark and app-icon direction;
- `02-entry-home.png` — splash, onboarding and venue cards;
- `03-store-box-flow.png` — venue detail, compact box cards and box-detail sheet;
- `04-checkout-states.png` — cart, payment success and payment failure;
- `05-navigation-profile.png` — map, favorites, orders and profile.

Application markup must use semantic tokens from `app/globals.css` and primitives from `components/ui-kit.tsx`. The boards are visual references rather than a second source of token values.
