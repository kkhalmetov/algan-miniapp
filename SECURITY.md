# Security policy

## Supported version

Security fixes are applied to the version deployed from the `main` branch.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to `algansupport@gmail.com`. Include the affected URL or component, reproduction steps and potential impact. Do not include bot tokens, access tokens, Telegram `initData`, payment details or personal data in a public GitHub issue.

We aim to acknowledge a report within three business days. Confirmed issues are fixed and deployed before public disclosure whenever practical.
